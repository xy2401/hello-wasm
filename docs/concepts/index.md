# WebAssembly 基础概念

WebAssembly 是一种可移植的低级字节码格式。浏览器或独立运行时负责验证模块、分配线性内存，并按照显式导入导出连接宿主能力。

## 模块

`.wasm` 文件包含类型、函数、表、内存、全局变量、导入和导出。它不等同于完整操作系统进程，也不会天然获得文件、网络或终端权限。

## 线性内存

模块通过连续字节数组访问内存。语言运行时需要自行管理对象布局、栈、堆和垃圾回收，或者依赖 WebAssembly GC 等扩展能力。

## 宿主接口

浏览器 JavaScript、WASI Runtime 或 container2wasm 的兼容层都是宿主。模块能够做什么，取决于宿主明确提供了哪些导入。
