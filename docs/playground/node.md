# Node Playground

一份 RISC-V 64 资产提供 JavaScript、TypeScript 与 HTML/CSS 工程工具。它既能直接执行 Node.js 脚本，也能演示 Pug、Sass 和 PostCSS 的源码转换流程。

## 包含工具

- Node.js 与 npm
- TypeScript 编译器
- Pug 与 html-validate
- Sass、PostCSS、Autoprefixer 与 Stylelint

原生 HTML 和 CSS 不需要编译；这里展示的是现代前端工程中的可选构建链。
